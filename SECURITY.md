# Security Policy

## Supported Versions

The following versions of the Quantum Trading Bot are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

We take the security and integrity of automated trading systems very seriously. If you discover a vulnerability or security flaw, please report it following these guidelines:

1. **Do not create public GitHub issues or forum posts** for potential vulnerabilities.
2. Submit your findings directly via private disclosure to the project security maintainers.
3. Include clear steps to reproduce, relevant logs, and environment configurations (ensure credentials, passwords, and private tokens are redacted).
4. Our security team will acknowledge receipt of reports within 48 hours and provide a remediation timeline.
5. All security updates and patches follow strict DevSecOps verification (0 Critical / 0 High findings) prior to deployment.
